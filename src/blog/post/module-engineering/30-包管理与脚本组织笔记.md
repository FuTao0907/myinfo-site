# 一、yarn 常用命令

```bash
yarn add axios
yarn add -D typescript
yarn remove axios
yarn install
```

- 原理总结：运行时依赖和开发依赖分开装，锁文件统一提交。
- 注意点：别混用不同包管理器生成多套锁文件。

# 二、scripts 基线

```json
{
  "scripts": {
    "dev": "next dev",
    "build": "next build",
    "start": "next start",
    "lint": "eslint .",
    "type-check": "tsc --noEmit",
    "test": "vitest run"
  }
}
```

- 原理总结：开发、构建、校验、测试脚本先统一命名。
- 注意点：脚本名统一后，CI 和团队协作会顺很多。

# 三、依赖分类

- `dependencies`：运行时必须存在。
- `devDependencies`：只在开发、构建、测试阶段使用。
- 锁文件必须提交，避免团队环境不一致。
