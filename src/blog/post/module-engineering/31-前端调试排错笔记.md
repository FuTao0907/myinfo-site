<small>排错最重要的是顺序，这篇只留最实用的检查流程。</small>

# 一、先看 Console

- 是否有运行时报错。
- 是否有资源加载报错。
- 是否有 Promise 未处理异常。

# 二、再看 Network

- URL 对不对。
- Method 对不对。
- Header 对不对。
- 状态码是什么。
- 响应体说了什么。

# 三、再看 Application

- cookie 是否存在。
- localStorage / sessionStorage 是否写进去。
- token 是否过期。

# 四、最后看 Performance

- 首屏慢看主线程。
- 交互卡看长任务。
- 滚动卡看回调是否太重。
