# 一、localStorage

```ts
/**
 * 保存 JSON 到 localStorage。
 */
function setLocalJSON<T>(key: string, value: T) {
  localStorage.setItem(key, JSON.stringify(value))
}

/**
 * 从 localStorage 读取 JSON。
 */
function getLocalJSON<T>(key: string): T | null {
  const raw = localStorage.getItem(key)
  return raw ? (JSON.parse(raw) as T) : null
}
```

- 原理总结：存入前先序列化，读取后再反序列化。
- 注意点：不要把敏感信息直接长久存进 localStorage。

# 二、sessionStorage

```ts
/**
 * 保存当前会话数据。
 */
function setSessionValue(key: string, value: string) {
  sessionStorage.setItem(key, value)
}
```

- 原理总结：`sessionStorage` 生命周期绑定当前标签页会话。
- 注意点：关闭标签页后数据会消失。

# 三、cookie

```ts
/**
 * 写入一个简单 cookie。
 */
function setCookie(name: string, value: string, days = 7) {
  const expires = new Date(Date.now() + days * 86400000).toUTCString()
  document.cookie = `${name}=${encodeURIComponent(value)}; expires=${expires}; path=/`
}

/**
 * 读取指定 cookie。
 */
function getCookie(name: string) {
  const match = document.cookie.match(new RegExp(`(?:^|; )${name}=([^;]*)`))
  return match ? decodeURIComponent(match[1]) : null
}
```

- 原理总结：cookie 本质是字符串，需要手动拼接和解析。
- 注意点：前端只能写非 `HttpOnly` cookie。

# 四、IndexedDB 最小模板

```ts
/**
 * 打开 IndexedDB 数据库。
 */
function openDB(name: string, version = 1) {
  return new Promise<IDBDatabase>((resolve, reject) => {
    const request = indexedDB.open(name, version)
    request.onerror = () => reject(request.error)
    request.onsuccess = () => resolve(request.result)
    request.onupgradeneeded = () => {
      const db = request.result
      // 首次初始化时创建对象仓库。
      if (!db.objectStoreNames.contains('items')) {
        db.createObjectStore('items', { keyPath: 'id' })
      }
    }
  })
}
```

- 原理总结：IndexedDB 通过数据库、仓库和事务管理大数据量本地存储。
- 注意点：复杂缓存或离线数据更适合 IndexedDB，不要全塞 localStorage。
