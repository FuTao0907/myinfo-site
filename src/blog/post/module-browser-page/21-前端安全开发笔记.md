# 一、XSS 基础防护

```ts
/**
 * 把文本安全写入节点。
 */
function setSafeText(element: HTMLElement, text: string) {
  // 用 textContent 写入，避免浏览器把内容当成 HTML 执行。
  element.textContent = text
}
```

- 原理总结：展示用户输入时优先走纯文本渲染，不给脚本执行机会。
- 注意点：能不用 `innerHTML` 就尽量不用。

# 二、上传校验

```ts
/**
 * 校验上传文件类型和大小。
 */
function validateUpload(file: File, acceptTypes: string[], maxSize: number) {
  const validType = acceptTypes.includes(file.type)
  const validSize = file.size <= maxSize
  return validType && validSize
}
```

- 原理总结：先在前端拦截明显不合规文件，减少无意义上传。
- 注意点：前端校验只是体验优化，服务端还得再校验一次。

# 三、token 与权限边界

- token 存储前先区分是否敏感。
- 前端隐藏按钮不等于真的有权限控制。
- 真正的权限判断必须放在服务端。

# 四、安全请求模板

```ts
/**
 * 统一附带鉴权头发送请求。
 */
async function securePost(url: string, data: unknown, token: string) {
  return fetch(url, {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      Authorization: `Bearer ${token}`,
    },
    body: JSON.stringify(data),
  })
}
```

- 原理总结：把鉴权信息放进统一请求层，避免每个调用点自己乱拼。
- 注意点：不要把“前端有 token”误以为等于“请求一定安全”。
