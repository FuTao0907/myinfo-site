<small>联调最怕来回猜问题，这篇直接按排查顺序来，优先保证能快速定位。</small>

# 一、先看 5 个基础项

- URL 对不对。
- Method 对不对。
- Header 对不对。
- Body / Query 对不对。
- 响应状态码是什么。

# 二、固定排查顺序

1. 先看浏览器 `Network`。
2. 再看响应体错误信息。
3. 再对照接口文档和字段定义。
4. 最后确认是否有跨域、代理、鉴权问题。

# 三、文件上传联调

- `Content-Type` 不要手写错边界。
- 字段名要和后端约定一致。
- 校验大小、类型和返回结构。

# 四、mock 与代理

- 本地没后端时优先 mock。
- 有后端但跨域时优先代理。
- 联调前统一 baseURL、token、环境变量。
