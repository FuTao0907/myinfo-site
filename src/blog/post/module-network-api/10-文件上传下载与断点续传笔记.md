# 一、这篇的边界

- 这篇讲传输协议、上传下载流程、分片和续传。

# 二、最常见上传格式

```http
Content-Type: multipart/form-data
```

- 原理总结：文件上传通常不是普通 JSON，而是带边界信息的表单流。
- 注意点：浏览器构造 `FormData` 时，不要手写 boundary。

# 三、分片上传

```text
选择文件
-> 前端按固定大小切片
-> 逐片上传
-> 服务端记录已完成分片
-> 最后通知服务端合并
```

- 原理总结：把大文件拆成小块，提升弱网稳定性并支持中断恢复。
- 注意点：切片只是第一步，真正断点续传需要服务端记住已上传分片。

# 四、断点续传

```text
读取上传记录
-> 跳过已成功分片
-> 只补传缺失分片
-> 合并后校验文件完整性
```

- 原理总结：续传的关键不是重新开始，而是知道“哪些块已经完成”。
- 注意点：大文件上传最好有 hash 或唯一文件标识。

# 五、下载与 Range

```http
Range: bytes=0-1023
```

- 原理总结：客户端可以只请求文件的一部分，服务端返回 `206 Partial Content`。
- 注意点：断点下载依赖服务端支持 Range 请求。
