# 二、超时与取消请求

```ts
/**
 * 给 fetch 增加超时控制。
 */
async function fetchWithTimeout(url: string, timeout = 5000) {
  const controller = new AbortController()
  // 到时间后主动中断请求，避免一直挂起。
  const timer = setTimeout(() => controller.abort(), timeout)

  try {
    const response = await fetch(url, { signal: controller.signal })
    return await response.json()
  } finally {
    clearTimeout(timer)
  }
}
```

- 原理总结：通过 `AbortController` 统一管理请求中断能力。
- 注意点：要区分超时取消和真正的接口报错。

# 三、串行与并行

```ts
/**
 * 串行执行异步任务。
 */
async function runSerial<T>(tasks: Array<() => Promise<T>>) {
  const results: T[] = []

  for (const task of tasks) {
    // 上一个完成之后才执行下一个。
    results.push(await task())
  }

  return results
}

/**
 * 并行执行异步任务。
 */
async function runParallel<T>(tasks: Array<() => Promise<T>>) {
  // 一次性发起所有任务，整体等待完成。
  return Promise.all(tasks.map((task) => task()))
}
```

- 原理总结：串行保顺序，并行保速度。
- 注意点：并行任务太多时，记得加并发限制。

# 四、重试与轮询

```ts
/**
 * 请求失败后按次数重试。
 */
async function requestRetry<T>(task: () => Promise<T>, count = 3): Promise<T> {
  let errorCache: unknown

  for (let i = 0; i < count; i += 1) {
    try {
      return await task()
    } catch (error) {
      errorCache = error
    }
  }

  throw errorCache
}

/**
 * 轮询直到满足停止条件。
 */
async function poll<T>(task: () => Promise<T>, stop: (data: T) => boolean, delay = 2000) {
  while (true) {
    const data = await task()
    if (stop(data)) return data
    await new Promise((resolve) => setTimeout(resolve, delay))
  }
}
```

- 原理总结：重试靠重复执行，轮询靠循环加延时。
- 注意点：轮询一定要有停止条件，不然会无限请求。

# 五、并发限制

```ts
/**
 * 限制同时进行的异步任务数量。
 */
async function limitConcurrency<T>(tasks: Array<() => Promise<T>>, limit = 3) {
  const result: T[] = []
  let current = 0

  async function worker() {
    while (current < tasks.length) {
      const index = current
      current += 1
      // 每个 worker 持续领取下一个任务，直到队列为空。
      result[index] = await tasks[index]()
    }
  }

  await Promise.all(Array.from({ length: limit }, worker))
  return result
}
```

- 原理总结：把任务队列交给多个 worker 共享消费。
- 注意点：下载、上传、大量详情请求最适合加并发限制。
