# 一、单行省略

```css
.ellipsis {
  overflow: hidden;
  text-overflow: ellipsis;
  white-space: nowrap;
}
```

- 原理总结：隐藏溢出内容，超出部分用省略号代替。
- 注意点：元素必须有宽度或宽度约束。

# 二、多行截断

```css
.line-clamp-2 {
  overflow: hidden;
  display: -webkit-box;
  -webkit-line-clamp: 2;
  -webkit-box-orient: vertical;
}
```

- 原理总结：通过盒模型限制最大显示行数。
- 注意点：这是常见方案，但依赖特定浏览器实现。

# 三、毛玻璃

```css
.glass {
  background: rgba(255, 255, 255, 0.2);
  backdrop-filter: blur(12px);
}
```

- 原理总结：半透明背景叠加背景模糊形成毛玻璃效果。
- 注意点：低性能设备上不要大面积滥用。

# 四、骨架屏与吸顶

```css
.skeleton {
  background: linear-gradient(90deg, #eee 25%, #f5f5f5 37%, #eee 63%);
  background-size: 400% 100%;
  animation: skeleton-loading 1.4s ease infinite;
}

.sticky-header {
  position: sticky;
  top: 0;
  z-index: 10;
}
```

- 原理总结：骨架屏解决等待感，sticky 解决滚动中的导航可见性。
- 注意点：吸顶元素记得处理背景色和层级。
