<small>响应式最适合做模板，写页面时直接拿来套比临时想断点快很多。</small>

# 一、媒体查询

```css
@media (max-width: 768px) {
  .sidebar {
    display: none;
  }
}
```

- 原理总结：在指定断点下覆盖默认布局。
- 注意点：断点命名最好统一，不要全项目随手乱写。

# 二、响应式字号

```css
.title {
  font-size: clamp(24px, 4vw, 40px);
}
```

- 原理总结：`clamp` 把最小值、弹性值、最大值合成一个公式。
- 注意点：比纯 `vw` 更稳，不容易在超大屏或超小屏失控。

# 三、移动端改一列

```css
.list {
  display: grid;
  grid-template-columns: repeat(3, minmax(0, 1fr));
  gap: 16px;
}

@media (max-width: 768px) {
  .list {
    grid-template-columns: 1fr;
  }
}
```

- 原理总结：桌面多列，移动端统一降成单列。
- 注意点：除了列数，还要一起检查间距、字号和按钮尺寸。

# 四、响应式图片

```html
<picture>
  <source media="(max-width: 768px)" srcset="/images/mobile.webp" />
  <img src="/images/desktop.webp" alt="cover" />
</picture>
```

- 原理总结：按设备条件返回不同图片资源。
- 注意点：移动端图片不要只是视觉缩小，资源体积也要缩小。
